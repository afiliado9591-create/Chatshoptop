Vai ficar em: minha-loja.alibr.com.br — use só letras minúsculas, números e hífen.

2. Aparência

Arraste pra esquerda pra deixar mais transparente (vê a foto por trás), ou pra direita pra deixar mais sólido.

3. Produtos

3b. Perguntas e Respostas

Cadastre dúvidas comuns (prazo de entrega, trocas, formas de pagamento...). O bot responde automaticamente quando o cliente perguntar algo parecido.

4. Publicar

Preencha os dados e clique em publicar. O link do cliente aparece aqui.

5. Alternativas manuais

Imagem: use um link direto ou faça upload do aparelho. A imagem enviada fica embutida no HTML.
